## 📌 About This Repository

This repository documents my structured path in Data Structures and Algorithms using **C++**. 

Rather than listing theoretical topics, this repository tracks **actual, code-verified implementations** developed step-by-step—from basic control flow and pattern generation through array algorithms, bit manipulation, and node-based data structures.

## 🚀 How to Run Locally

Each file is self-contained and can be compiled using any modern C++ compiler (`g++` / `clang++`):

1. **Clone the repository:**
   ```bash
   git clone https://github.com/lakshyakurvey19-code/DSA-in-Cpp.git
   cd DSA-in-Cpp
   ```

2. **Compile any file:**
   ```bash
   g++ "6. Array/001_binarySearch.cpp" -o binarySearch
   ```

3. **Run the executable:**
   ```bash
   ./binarySearch
   ```
